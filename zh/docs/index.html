关于 文档

精简高效的文档编辑器，支持 DOCX、DOC 和 RTF 文档的阅读与编辑，具备段落样式、表格排版及一键导出 PDF 功能。

主要功能与特性

高保真 DOCX 兼容

完美打开与编辑 Microsoft Word 文档，完整保留原有复杂排版与格式。

丰富排版体系

支持字号字体、标题层级、项目符号、对齐缩进等全套字符与段落样式。

表格与图文混排

灵活插入并调整表格大小、插入高画质图片及精准分页符。

实时字数统计

输入时动态统计字数、字符数、句子数及当前页数。

一键导出 PDF

轻点一下即可将文档即时渲染转换为印刷品质的 PDF 文件。
