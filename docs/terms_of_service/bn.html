সেবার শর্তাবলী

Docs

1. চুক্তির স্বীকৃতি

এই সেবার শর্তাবলী Mohan MRKS দ্বারা নির্মিত নথি সম্পাদক Docs অ্যাপ্লিকেশনের ব্যবহার পরিচালনা করে। এই অ্যাপটি ইনস্টল বা ব্যবহার করার মাধ্যমে, আপনি এই শর্তাবলী দ্বারা আইনত আবদ্ধ হতে সম্মত হচ্ছেন। আপনি এই শর্তাবলী না মানলে অনুগ্রহ করে অ্যাপটি ইনস্টল বা ব্যবহার করবেন না।

2. অ্যাপের যথাযথ ব্যবহার

আইনসম্মত উদ্দেশ্যে নথি তৈরি, প্রদর্শন, সম্পাদনা, সংগঠিত এবং রপ্তানি করতে আপনি Docs ব্যবহার করতে পারেন। আপনি যে কোনো সামগ্রী তৈরি, উন্মুক্ত বা সম্পাদনা করেন তার বৈধতার জন্য আপনি সম্পূর্ণ দায়ী এবং নিশ্চিত করবেন যে সেই সামগ্রী ব্যবহারের জন্য প্রয়োজনীয় সমস্ত আইনি অধিকার আপনার রয়েছে।

3. আপনার ফাইল এবং ব্যাকআপ দায়িত্ব

Docs স্থানীয়ভাবে ডিভাইসে বা আপনার নির্বাচিত স্থানে সংরক্ষিত নথিগুলির সাথে কাজ করার জন্য তৈরি। উপযুক্ত ফাইল নির্বাচন করা, রপ্তানির ফলাফল যাচাই করা এবং গুরুত্বপূর্ণ তথ্যের নিয়মিত স্বাধীন ব্যাকআপ রাখা সম্পূর্ণ আপনার দায়িত্ব। ডেটা মুছে ফেলা বা পরিবর্তনের সম্ভাবনা রয়েছে এমন ক্রিয়াকলাপের আগে সর্বদা একটি পৃথক অনুলিপি রাখুন। আপনার ডিভাইস থেকে হারিয়ে যাওয়া ফাইল বিকাশকারী পুনরুদ্ধার করতে অক্ষম।

4. সুরক্ষিত ফাইল এবং পাসওয়ার্ড নিরাপত্তা

অ্যাপের নথি সুরক্ষা বৈশিষ্ট্যের সাথে ব্যবহৃত পাসওয়ার্ড সুরক্ষিত রাখা সম্পূর্ণ আপনার দায়িত্ব। বিকাশকারী ভুলে যাওয়া পাসওয়ার্ড পুনরুদ্ধার করতে পারে না এবং সঠিক পাসওয়ার্ড ছাড়া এনক্রিপ্ট করা ফাইল ডিক্রিপ্ট করতে পারে না।

5. তৃতীয় পক্ষের সেবা এবং ওপেন সোর্স সফটওয়্যার

কিছু বৈশিষ্ট্য ওয়েবসাইট খুলতে পারে বা তৃতীয় পক্ষের পরিষেবার মাধ্যমে সামগ্রী শেয়ার করতে পারে। সেই পরিষেবাগুলি তাদের নিজস্ব শর্তাবলী দ্বারা পরিচালিত হয়। Docs-এ অন্তর্ভুক্ত তৃতীয় পক্ষের ওপেন-সোর্স উপাদানগুলি তাদের প্রযোজ্য লাইসেন্সের অধীন।

6. উপলব্ধতা এবং ওয়্যারেন্টি অস্বীকৃতি

Docs অ্যাপটি কোনো প্রকাশ্য বা উহ্য ওয়ারেন্টি ছাড়াই "যেমন আছে" (AS IS) এবং "যেমন পাওয়া যায়" (AS AVAILABLE) ভিত্তিতে সরবরাহ করা হয়। অ্যাপটি নিরবচ্ছিন্ন বা ত্রুটিহীন থাকবে এমন কোনো নিশ্চয়তা বিকাশকারী দেয় না। আইন দ্বারা অনুমোদিত সর্বোচ্চ সীমা পর্যন্ত, ডেটা ক্ষতি সহ যে কোনো ক্ষতির জন্য বিকাশকারী দায়ী থাকবে না।

7. শর্তাবলীর পরিবর্তন এবং যোগাযোগ

অ্যাপের উন্নতির সাথে এই শর্তাবলী আপডেট করা হতে পারে। আপডেটের পরে অ্যাপ ব্যবহার চালিয়ে যাওয়ার অর্থ হলো আপনি পরিবর্তিত শর্তাবলী গ্রহণ করেছেন। প্রশ্নের জন্য: mohanmrks@yandex.com।
