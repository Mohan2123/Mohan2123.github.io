சேவை விதிமுறைகள்

Docs

1. ஒப்பந்தத்தை ஏற்றுக்கொள்வது

இந்த சேவை விதிமுறைகள் Mohan MRKS உருவாக்கிய Docs ஆவண எடிட்டர் செயலியின் பயன்பாட்டை நிர்வகிக்கின்றன. இந்த செயலியை நிறுவுவதன் மூலம் அல்லது பயன்படுத்துவதன் மூலம், இந்த விதிமுறைகளுக்கு சட்டப்பூர்வமாகக் கட்டுப்பட ஒப்புக்கொள்கிறீர்கள். இந்த விதிமுறைகளை ஏற்கவில்லை என்றால், செயலியைப் பயன்படுத்த வேண்டாம்.

2. பயன்பாட்டு நெறிமுறைகள்

சட்டப்பூர்வமான நோக்கங்களுக்காக ஆவணங்களை உருவாக்க, பார்க்க, திருத்த, ஒழுங்கமைக்க மற்றும் ஏற்றுமதி செய்ய மட்டுமே நீங்கள் Docs-ஐப் பயன்படுத்தலாம். நீங்கள் உருவாக்கும் அல்லது அணுகும் அனைத்து உள்ளடக்கத்திற்கும் நீங்களே முழுப் பொறுப்பாவீர்கள்.

3. உங்கள் கோப்புகள் மற்றும் காப்புப்பிரதி பொறுப்பு

Docs உள்ளூரில் சேமிக்கப்பட்டுள்ள ஆவணங்களுடன் செயல்படும் வகையில் வடிவமைக்கப்பட்டுள்ளது. கோப்புகளைத் தேர்ந்தெடுப்பது, முடிவுகளைச் சரிபார்ப்பது மற்றும் முக்கியமான ஆவணங்களின் காப்புப்பிரதிகளை (Backup) தொடர்ந்து பராமரிப்பது முற்றிலும் உங்கள் பொறுப்பாகும். கோப்புகளை மேலெழுதும் அல்லது நீக்கும் செயல்பாடுகளுக்கு முன் எப்போதும் தனி நகலை வைத்திருங்கள். உங்கள் சாதனத்திலிருந்து இழந்த கோப்புகளை டெவலப்பரால் மீட்டெடுக்க முடியாது.

4. பாதுகாக்கப்பட்ட கோப்புகள் மற்றும் கடவுச்சொல் பாதுகாப்பு

ஆவணப் பாதுகாப்பு அம்சத்திற்குப் பயன்படுத்தப்படும் கடவுச்சொற்களைப் பாதுகாப்பது உங்கள் தனிப்பட்ட பொறுப்பாகும். மறந்த கடவுச்சொற்களை டெவலப்பரால் மீட்டெடுக்க முடியாது மற்றும் கடவுச்சொல் இல்லாமல் கோப்பை மறைகுறியாக்க முடியாது.

5. மூன்றாம் தரப்பு சேவைகள் மற்றும் மென்பொருள்

சில அம்சங்கள் வலைத்தளங்களைத் திறக்கலாம் அல்லது மூன்றாம் தரப்பு சேவைகள் வழியாக உள்ளடக்கத்தைப் பகிரலாம். அந்த சேவைகள் அவற்றின் சொந்த விதிமுறைகளால் நிர்வகிக்கப்படுகின்றன. Docs திறந்த மூல மென்பொருட்களையும் (open source) உள்ளடக்கியுள்ளது.

6. உத்தரவாத மறுப்பு

Docs எந்தவிதமான உத்தரவாதமும் இன்றி "உள்ளவாறே" (AS IS) வழங்கப்படுகிறது. செயலி தடையின்றி இயங்கும் என்றோ அல்லது பிழைகளற்றது என்றோ டெவலப்பர் உத்தரவாதம் அளிக்கவில்லை. சட்டத்தால் அனுமதிக்கப்பட்ட அளவிற்கு, தரவு இழப்பு உள்ளிட்ட இழப்புகளுக்கு டெவலப்பர் பொறுப்பேற்க மாட்டார்.

7. மாற்றங்கள் மற்றும் தொடர்பு

செயலி மாற்றங்களுக்கு ஏற்ப விதிமுறைகள் புதுப்பிக்கப்படலாம். கேள்விகளுக்கு: mohanmrks@yandex.com.
