Docs

1. कराराची स्वीकृती

या सेवा अटी Mohan MRKS द्वारे विकसित दस्तऐवज संपादक Docs ॲप्लिकेशनच्या वापरावर नियंत्रण ठेवतात. हे ॲप इंस्टॉल करून किंवा वापरून, तुम्ही या अटींचे कायदेशीर पालन करण्यास सहमती दर्शवता. जर तुम्ही या अटींशी असहमत असाल, तर कृपया ॲप वापरू नका.

2. ॲपचा कायदेशीर वापर

कायदेशीर हेतूंसाठी दस्तऐवज तयार करण्यासाठी, पाहण्यासाठी, संपादित करण्यासाठी, व्यवस्थापित करण्यासाठी आणि निर्यात करण्यासाठी तुम्ही Docs वापरू शकता. तुम्ही तयार केलेल्या किंवा ॲक्सेस केलेल्या सर्व सामग्रीच्या वैधतेसाठी तुम्ही पूर्णपणे जबाबदार आहात.

3. तुमच्या फाइल्स आणि बॅकअपची जबाबदारी

Docs डिव्हाइसवर स्थानिक पातळीवर जतन केलेल्या दस्तऐवजांसह कार्य करण्यासाठी तयार केले आहे. योग्य फाइल्स निवडणे, निकालांची पडताळणी करणे आणि महत्त्वाच्या सामग्रीचा नियमित स्वतंत्र बॅकअप ठेवणे ही तुमची जबाबदारी आहे. फाइल्स बदलण्यापूर्वी किंवा हटवण्यापूर्वी नेहमी वेगळी प्रत ठेवा. डिव्हाइसवरून गमावलेल्या फाइल्स डेव्हलपर पुनर्प्राप्त करू शकत नाही.

4. संरक्षित फाइल्स आणि पासवर्ड सुरक्षा

दस्तऐवज संरक्षण वैशिष्ट्यासाठी वापरलेला पासवर्ड सुरक्षित ठेवणे ही तुमची वैयक्तिक जबाबदारी आहे. डेव्हलपर विसरलेला पासवर्ड पुनर्प्राप्त करू शकत नाही आणि पासवर्डशिवाय फाइल डीक्रिप्ट करू शकत नाही.

5. तृतीय-पक्ष सेवा आणि ओपन सोर्स सॉफ्टवेअर

काही वैशिष्ट्ये वेबसाइट उघडू शकतात किंवा बाह्य सेवांद्वारे सामग्री शेअर करू शकतात. त्या सेवा त्यांच्या स्वतःच्या नियमांद्वारे नियंत्रित केल्या जातात. Docs मध्ये तृतीय-पक्ष ओपन-सोर्स घटक समाविष्ट आहेत जे त्यांच्या परवान्यांच्या अधीन आहेत.

6. हमी अस्वीकरण

Docs ॲप कोणत्याही हमीशिवाय "जसे आहे तसे" (AS IS) आणि "जसे उपलब्ध आहे" (AS AVAILABLE) तत्त्वावर प्रदान केले जाते. डेटाच्या नुकसानासह कोणत्याही नुकसानीसाठी डेव्हलपर जबाबदार असणार नाही.
