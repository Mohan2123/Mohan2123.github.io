গোপনীয়তা নীতি

Docs

1. এই নীতি সম্পর্কে

এই গোপনীয়তা নীতি বিস্তারিতভাবে ব্যাখ্যা করে যে Mohan MRKS দ্বারা নির্মিত Docs অ্যাপ্লিকেশন ("Docs" বা "অ্যাপ") ব্যবহারের সময় কীভাবে আপনার তথ্য পরিচালনা ও সুরক্ষিত করে। Docs বিশেষভাবে আপনার ডিভাইসের মেমরিতে সংরক্ষিত নথিগুলি স্থানীয়ভাবে পরিচালনা এবং সম্পাদনা করার জন্য তৈরি করা হয়েছে। এই অ্যাপটি বিকাশকারী দ্বারা পরিচালিত কোনও অনলাইন ব্যবহারকারী অ্যাকাউন্ট বা ক্লাউড-ভিত্তিক নথি সিঙ্ক সেবা প্রদান করে না।

2. নথি এবং স্থানীয় সূচক

আপনার নথিগুলি সরাসরি আপনার ডিভাইসে বা আপনার নির্বাচিত স্থানীয় অবস্থানেই পড়া, সম্পাদনা এবং সংরক্ষণ করা হয়। Docs কখনই কোনো Docs সার্ভারে আপনার নথির সামগ্রী পাঠায় না। দ্রুত তালিকাভুক্তকরণ, তাৎক্ষণিক অনুসন্ধান এবং সহজে ফাইল সাজানোর জন্য, অ্যাপটি ডিভাইসে একটি স্থানীয় ডাটাবেস বজায় রাখে যাতে ফাইলের পাথ, নাম, এক্সটেনশন, আকার, পরিবর্তনের সময়, প্রিয় এবং সুরক্ষিত অবস্থা এবং অনুসন্ধানের জন্য সংগৃহীত টেক্সট পূর্বরূপ অন্তর্ভুক্ত থাকে। এই ডাটাবেস এবং এর পূর্বরূপগুলি সম্পূর্ণরূপে আপনার ডিভাইসে থাকে এবং অ্যাপের ডেটা মুছে ফেললে বা অ্যাপ আনইনস্টল করলে তা সম্পূর্ণ মুছে ফেলা হয়; অ্যাপের ব্যক্তিগত স্টোরেজের বাইরে সংরক্ষিত মূল ফাইলগুলি আপনার ডিভাইসে অক্ষত থাকে।

Android সিস্টেমে, Docs নথিগুলি খুঁজে পেতে এবং পরিচালনা করতে সমর্থিত Android সংস্করণগুলিতে "সমস্ত ফাইল অ্যাক্সেস" (All-Files Access) সহ স্টোরেজ অনুমতির অনুরোধ করতে পারে। অন্যান্য অপারেটিং সিস্টেমে, সিস্টেমের ডিফল্ট ফাইল নির্বাচন এবং স্টোরেজ ব্যবস্থার মাধ্যমে অ্যাক্সেস সরবরাহ করা হয়।

3. পাসওয়ার্ড সুরক্ষিত নথি

আপনি যখন "সুরক্ষিত করুন ও সংরক্ষণ করুন" বৈশিষ্ট্যটি নির্বাচন করেন, তখন Docs আপনার পাসওয়ার্ড থেকে PBKDF2-HMAC-SHA-256 এর মাধ্যমে প্রস্তুতকৃত একটি এনক্রিপশন কী এবং শক্তিশালী AES-256-GCM মান ব্যবহার করে ফাইলটি সম্পূর্ণ এনক্রিপ্ট করে। এই পাসওয়ার্ড কখনই বিকাশকারীর কাছে পাঠানো বা সংরক্ষণ করা হয় না। দয়া করে আপনার পাসওয়ার্ডটি নিরাপদে রাখুন: ভুলে যাওয়া পাসওয়ার্ড বিকাশকারী কর্তৃক কোনোভাবেই পুনরুদ্ধার করা সম্ভব নয় এবং এর কারণে সুরক্ষিত ফাইলটি স্থায়ীভাবে অপ্রবেশযোগ্য হয়ে যেতে পারে।

4. ডায়াগনস্টিকস এবং ত্রুটি রিপোর্ট

প্রযুক্তিগত সমস্যা সমাধান এবং স্থায়িত্ব উন্নত করার জন্য, Docs অ্যাপের ব্যক্তিগত স্থানীয় স্টোরেজে একটি ডায়াগনস্টিক ফাইলে অ্যাপ্লিকেশনের ত্রুটির বিবরণ (যেমন ত্রুটির বার্তা এবং স্ট্যাক ট্রেস) সংরক্ষণ করে। এই ডায়াগনস্টিক রিপোর্টগুলি Docs দ্বারা নেটওয়ার্কের মাধ্যমে স্বয়ংক্রিয়ভাবে কখনই কোথাও পাঠানো হয় না। ফাইলের আকার বৃদ্ধির সাথে সাথে এটি স্থানীয়ভাবে আবর্তিত হয়। ত্রুটির বিবরণে প্রাসঙ্গিক তথ্য থাকতে পারে, তাই নিজে পর্যালোচনা না করে ডায়াগনস্টিক ফাইল অন্যদের সাথে ভাগ করা থেকে বিরত থাকুন।

5. নেটওয়ার্ক এবং তৃতীয় পক্ষের সেবা

আপনার দ্বারা শুরু করা কিছু নির্দিষ্ট ক্রিয়া Docs-এর বাইরের পরিষেবাগুলির সাথে যোগাযোগ করতে পারে, যেমন কোনো URL থেকে ফাইল ডাউনলোড করা, ইন-অ্যাপ ব্রাউজারে ওয়েবসাইট খোলা, সিস্টেম শেয়ারিং মেনুর মাধ্যমে ফাইল ভাগ করা, বা ইমেলের মাধ্যমে সহায়তা দলের সাথে যোগাযোগ করা। এই বাহ্যিক পরিষেবাগুলি আপনার আইপি ঠিকানা, অনুরোধ করা URL বা আপনার নির্বাচিত সামগ্রীর মতো প্রযুক্তিগত তথ্য গ্রহণ করতে পারে। সেইসব তৃতীয় পক্ষের পরিষেবার নিজস্ব স্বাধীন গোপনীয়তা নীতি প্রযোজ্য হবে। Docs-এর বাহ্যিক পরিষেবাগুলির উপর কোনো নিয়ন্ত্রণ বা দায়বদ্ধতা নেই।

6. ডেটা নিয়ন্ত্রণ এবং যোগাযোগের বিবরণ

আপনি Docs এবং আপনার ডিভাইসের ফাইল সরঞ্জামগুলি ব্যবহার করে যেকোনো সময় আপনার নথিগুলি স্বাধীনভাবে পরিচালনা, পরিবর্তন বা মুছে ফেলতে পারেন। অ্যাপ ডেটা মুছে ফেলা হলে স্থানীয় অনুসন্ধান সূচক এবং ডায়াগনস্টিক লগগুলি সম্পূর্ণ মুছে যায়; তবে এটি আপনার ডিভাইসের অন্যান্য ফোল্ডারে সংরক্ষিত নথিগুলিকে মুছে ফেলে না। গোপনীয়তা সংক্রান্ত প্রশ্নের জন্য, অনুগ্রহ করে ইমেলের মাধ্যমে যোগাযোগ করুন: mohanmrks@yandex.com।

7. নীতি পরিবর্তন

Docs অ্যাপটি উন্নত এবং নতুন বৈশিষ্ট্যের সাথে আপডেট হওয়ার সাথে সাথে এই গোপনীয়তা নীতি সময়ে সময়ে আপডেট করা হতে পারে। এই নীতি পর্যায়ক্রমে পর্যালোচনা করা হতে পারে।
