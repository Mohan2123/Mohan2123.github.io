गोपनीयता नीति

Docs

1. इस नीति के बारे में

यह नीति विस्तार से बताती है कि Mohan MRKS द्वारा विकसित Docs एप्लिकेशन ("Docs" या "ऐप") उपयोग के दौरान आपकी जानकारी को कैसे संभालता है। Docs विशेष रूप से आपके डिवाइस पर स्थानीय रूप से संग्रहीत दस्तावेज़ों को प्रबंधित और संपादित करने के लिए डिज़ाइन किया गया है। यह ऐप डेवलपर द्वारा संचालित कोई ऑनलाइन खाता या क्लाउड दस्तावेज़ सिंक सेवा प्रदान नहीं करता है।

2. दस्तावेज़ और स्थानीय इंडेक्स

आपके सभी दस्तावेज़ केवल आपके डिवाइस पर या आपके द्वारा चुने गए विशिष्ट स्थानों पर ही पढ़े, संपादित और सहेजे जाते हैं। Docs कभी भी आपके दस्तावेज़ों की सामग्री को किसी भी Docs सर्वर पर नहीं भेजता है। फ़ाइलों को सूचीबद्ध करने, तुरंत खोजने और व्यवस्थित करने के लिए, ऐप आपके डिवाइस पर एक स्थानीय डेटाबेस बनाए रखता है जिसमें फ़ाइल पथ, फ़ाइल नाम, एक्सटेंशन, आकार, संशोधन समय, पसंदीदा और सुरक्षित स्थिति, और त्वरित खोज के लिए निकाले गए टेक्स्ट पूर्वावलोकन शामिल होते हैं। यह डेटाबेस और इसके टेक्स्ट पूर्वावलोकन केवल डिवाइस पर ही रहते हैं और ऐप का डेटा साफ़ करने या ऐप को अनइंस्टॉल करने पर पूरी तरह से हटा दिए जाते हैं; ऐप के निजी स्टोरेज के बाहर सहेजे गए मूल दस्तावेज़ आपके डिवाइस पर सुरक्षित बने रह सकते हैं।

Android ऑपरेटिंग सिस्टम पर, Docs दस्तावेज़ों को खोजने और प्रबंधित करने के लिए स्टोरेज एक्सेस की अनुमति मांग सकता है (जिसमें समर्थित Android वर्ज़न पर "सभी फ़ाइलों तक पहुँच" यानी All-Files Access शामिल है)। अन्य ऑपरेटिंग सिस्टम प्लेटफ़ॉर्म पर, एक्सेस सिस्टम के डिफ़ॉल्ट फ़ाइल चयन और स्टोरेज तंत्र के माध्यम से प्रदान की जाती है।

3. पासवर्ड द्वारा सुरक्षित दस्तावेज़

जब आप ऐप में "सुरक्षित करें और सहेजें" विकल्प चुनते हैं, तो Docs आपके द्वारा सेट किए गए पासवर्ड से PBKDF2-HMAC-SHA-256 के माध्यम से उत्पन्न एन्क्रिप्शन कुंजी और मजबूत AES-256-GCM एल्गोरिदम का उपयोग करके निर्यातित दस्तावेज़ को पूरी तरह से एन्क्रिप्ट करता है। यह पासवर्ड कभी भी डेवलपर को अपलोड या प्रेषित नहीं किया जाता है। कृपया अपने पासवर्ड को सुरक्षित रखें: भूले हुए पासवर्ड को डेवलपर द्वारा किसी भी तकनीक से पुनर्प्राप्त नहीं किया जा सकता है, और इसके बिना वह सुरक्षित फ़ाइल हमेशा के लिए अगम्य हो सकती है।

4. डायग्नोस्टिक्स और त्रुटि लॉग

समस्या निवारण और तकनीकी सुधार के लिए, Docs ऐप के निजी स्थानीय स्टोरेज में एक डायग्नोस्टिक फ़ाइल में एप्लिकेशन त्रुटि विवरण (जैसे त्रुटि संदेश और स्टैक ट्रेस) लिखता है। ये रिपोर्ट Docs द्वारा नेटवर्क पर स्वचालित रूप से कभी प्रेषित नहीं की जाती हैं। फ़ाइल का आकार बढ़ने पर इसे स्थानीय रूप से घुमाया (रोटेट) जाता है। त्रुटि विवरण में संदर्भगत जानकारी शामिल हो सकती है, इसलिए जब तक आप स्वयं इसकी समीक्षा न कर लें, तब तक डायग्नोस्टिक फ़ाइलों को किसी के साथ साझा करने से बचें।

5. नेटवर्क और तृतीय-पक्ष सेवाएँ

उपयोगकर्ता द्वारा अपनी इच्छा से शुरू की गई कुछ क्रियाएं Docs के बाहर की सेवाओं के साथ संचार कर सकती हैं, जैसे किसी URL से फ़ाइल डाउनलोड करना, इन-ऐप ब्राउज़र में वेबसाइट खोलना, ऑपरेटिंग सिस्टम के ज़रिये फ़ाइल साझा करना, या ईमेल द्वारा सहायता टीम से संपर्क करना। वे तृतीय-पक्ष सेवाएँ आपके आईपी पते, अनुरोधित URL, या आपके द्वारा साझा की जाने वाली सामग्री जैसी तकनीकी जानकारी प्राप्त कर सकती हैं। उन सेवाओं की अपनी स्वतंत्र गोपनीयता नीतियां लागू होती हैं। Docs का उन बाहरी सेवाओं पर कोई नियंत्रण नहीं है।

6. डेटा नियंत्रण और संपर्क जानकारी

आप Docs और अपने डिवाइस के फ़ाइल टूल का उपयोग करके किसी भी समय अपने दस्तावेज़ों को प्रबंधित, संपादित या हटा सकते हैं। ऐप का डेटा साफ़ करने से इसका स्थानीय इंडेक्स और डायग्नोस्टिक्स हट जाते हैं; लेकिन इससे आपके डिवाइस के अन्य फ़ोल्डरों में संग्रहीत दस्तावेज़ अपने आप नहीं हटते हैं। गोपनीयता से संबंधित किसी भी प्रश्न के लिए, कृपया ईमेल द्वारा संपर्क करें: mohanmrks@yandex.com।

7. नीति में परिवर्तन

Docs ऐप में सुधार और नई सुविधाओं के साथ इस नीति को समय-समय पर अपडेट किया जा सकता है। इस नीति की समय-समय पर समीक्षा की जा सकती है।
