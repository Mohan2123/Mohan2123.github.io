隐私政策

Docs

1. 关于本政策

本政策详细说明了由 Mohan MRKS 开发的 Docs 应用程序（以下简称“Docs”或“本应用”）在您使用时如何处理信息。Docs 专为管理和编辑存储在您设备上的本地文档而设计。本应用不提供任何由开发者运营的在线账户服务，亦不提供任何远程云端文档同步服务。

2. 文档与本地索引

您的所有文档均在您的设备本地或您自主选定的存储位置进行读取、编辑和保存。Docs 绝不会将您的任何文档内容上传或发送至任何 Docs 服务器。为了实现文档的列表展示、即时搜索与分类整理，本应用在设备内部维护一个本地数据库，其中记录了文件路径、文件名、文件扩展名、文件大小、最后修改时间、收藏状态、加密保护状态，以及专门提取用于快速文本搜索的文本预览摘要。该数据库及其文本预览内容完全保存在您的设备本地，当您选择清除应用数据或彻底卸载应用时，这些索引数据将被完全移除；而保存在本应用私有沙盒存储空间之外的原始文档文件仍将安全保留在您的设备中。

在 Android 操作系统上，Docs 可能会请求设备存储访问权限（包括在受支持的 Android 版本上请求“所有文件访问权限”），以实现查找和管理设备中文档的功能。在其他操作系统平台上，文档访问则是通过操作系统原生的文件选择器与安全存储机制来进行授权。

3. 加密保护文档

当您在应用内选择“加密保护并保存”功能时，Docs 会采用高强度的 AES-256-GCM 算法对导出的文档文件进行全面加密，加密密钥通过 PBKDF2-HMAC-SHA-256 算法直接由您设置的密码衍生得出。此密码绝不会以任何明文或密文形式上传给开发者。请务必妥善保管您的密码：一旦遗忘密码，开发者在技术上完全无法协助恢复，且可能导致该加密保护文件永久无法再次解密或访问。

4. 故障诊断日志

为了便于进行故障排查和稳定性优化，Docs 会将应用程序出现的错误详情（例如具体的错误消息和调用堆栈跟踪）写入位于应用本地私有沙盒存储中的诊断日志文件中。这些诊断报告绝不会被 Docs 自动上传或传输至任何网络服务。随着日志文件的增长，系统会在本地对其进行轮替和覆盖。错误详情中可能包含发生错误时特定环境上下文中的部分信息，因此在您亲自核实审查日志内容之前，请勿随意将诊断文件对外分享。

5. 网络及第三方服务

由您主动发起的某些特定操作可能会与 Docs 应用外部的第三方服务进行网络通信，包括通过网络链接 URL 下载文件、在内置应用浏览器中访问外部网站、通过操作系统的系统分享菜单分享文档，或者通过电子邮件客户端联系技术支持团队。这些外部服务在交互过程中可能会接收到您的 IP 地址、请求的 URL 链接或您主动选择分享的具体文档内容。这些外部服务的行为完全受其各自独立的隐私政策约束。Docs 对这些第三方外部服务没有任何控制权或法律管辖力。

6. 数据自主权与联系方式

您可以随时通过 Docs 应用以及您设备自带的文件管理工具，自主管理、重命名、导出或删除您的任何文档。清除本应用的数据将彻底清除本地创建的索引数据库与错误诊断日志；但此操作绝不会自动删除您保存在设备其他公开目录中的个人文档。如果您对本隐私政策有任何疑问或需要咨询，请通过电子邮件与我们取得联系：mohanmrks@yandex.com。

7. 政策变更与更新

随着 Docs 应用的功能迭代和版本改进，本政策可能会适时进行修订。本政策可能会定期进行更新。
