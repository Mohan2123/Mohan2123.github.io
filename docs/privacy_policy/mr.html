गोपनीयता धोरण

Docs

1. या धोरणाबद्दल

हे गोपनीयता धोरण Mohan MRKS द्वारे विकसित Docs ॲप्लिकेशन ("Docs" किंवा "ॲप") वापरताना तुमची माहिती कशी हाताळते आणि सुरक्षित ठेवते हे तपशीलवार स्पष्ट करते. Docs विशेषतः तुमच्या डिव्हाइसच्या मेमरीमध्ये स्थानिक पातळीवर संग्रहित दस्तऐवज व्यवस्थापित आणि संपादित करण्यासाठी डिझाइन केलेले आहे. हे ॲप डेव्हलपरद्वारे चालवले जाणारे कोणतेही ऑनलाइन खाते किंवा क्लाउड-आधारित दस्तऐवज सिंक्रोनाइझेशन सेवा प्रदान करत नाही.

2. दस्तऐवज आणि स्थानिक अनुक्रमणिका

तुमचे सर्व दस्तऐवज केवळ तुमच्या डिव्हाइसवर किंवा तुम्ही निवडलेल्या स्थानिक स्टोरेज स्थानांवरच वाचले, संपादित केले आणि जतन केले जातात. Docs कोणत्याही Docs सर्व्हरवर तुमच्या दस्तऐवजांची सामग्री कधीही पाठवत नाही. फाइल्सची सूची तयार करण्यासाठी, त्वरित शोधण्यासाठी आणि व्यवस्थापित करण्यासाठी, ॲप तुमच्या डिव्हाइसवर स्थानिक डेटाबेस ठेवते ज्यामध्ये फाइल पाथ, नावे, एक्स्टेंशन, आकार, बदललेली वेळ, आवडते आणि संरक्षित स्थिती, आणि जलद शोधासाठी काढलेले मजकूर पूर्वावलोकन समाविष्ट असते. हा डेटाबेस आणि पूर्वावलोकने केवळ डिव्हाइसवरच राहतात आणि ॲपचा डेटा साफ केल्यास किंवा ॲप अनइंस्टॉल केल्यास पूर्णपणे काढून टाकले जातात; ॲपच्या खाजगी स्टोरेजबाहेर जतन केलेल्या मूळ फाइल्स तुमच्या डिव्हाइसवर सुरक्षित राहतात.

Android ऑपरेटिंग सिस्टमवर, Docs दस्तऐवज शोधण्यासाठी आणि व्यवस्थापित करण्यासाठी समर्थित Android आवृत्त्यांवर "सर्व फाइल्स ॲक्सेस" (All-Files Access) सह स्टोरेज परवानगीची विनंती करू शकते. इतर ऑपरेटिंग सिस्टमवर, सिस्टमच्या डीफॉल्ट फाइल निवड आणि स्टोरेज यंत्रणेद्वारे प्रवेश प्रदान केला जातो.

3. पासवर्डने संरक्षित दस्तऐवज

जेव्हा तुम्ही "संरक्षित करा आणि जतन करा" हे वैशिष्ट्य निवडता, तेव्हा Docs तुमच्या पासवर्डवरून PBKDF2-HMAC-SHA-256 द्वारे तयार केलेली एन्क्रिप्शन की आणि मजबूत AES-256-GCM अल्गोरिदम वापरून दस्तऐवज पूर्णपणे कूटबद्ध (encrypt) करते. हा पासवर्ड कधीही डेव्हलपरला पाठवला जात नाही किंवा सर्व्हरवर साठवला जात नाही. कृपया तुमचा पासवर्ड सुरक्षित ठिकाणी ठेवा: विसरलेला पासवर्ड डेव्हलपरद्वारे कोणत्याही प्रकारे पुनर्प्राप्त केला जाऊ शकत नाही आणि तो गमावल्यास संरक्षित फाइल कायमची अनुपलब्ध होऊ शकते.

4. त्रुटी निवारण आणि निदान लॉग

तांत्रिक समस्यांचे निवारण करण्यासाठी आणि ॲपची स्थिरता सुधारण्यासाठी, Docs ॲपच्या खाजगी स्थानिक स्टोरेजमधील डायग्नोस्टिक फाइलमध्ये ॲप्लिकेशन त्रुटी तपशील (जसे की त्रुटी संदेश आणि स्टॅक ट्रेस) नोंदवते. हे डायग्नोस्टिक अहवाल Docs द्वारे नेटवर्कवर आपोआप कधीही पाठवले जात नाहीत. फाइलचा आकार वाढल्यास ती स्थानिक पातळीवर फिरवली जाते. त्रुटी तपशीलांमध्ये संदर्भ माहिती असू शकते, म्हणून स्वतः तपासल्याशिवाय डायग्नोस्टिक फाइल्स इतरांशी शेअर करणे टाळा.

5. नेटवर्क आणि तृतीय-पक्ष सेवा

वापरकर्त्याने सुरू केलेल्या काही क्रिया Docs बाहेरील सेवांशी संवाद साधू शकतात, जसे की URL वरून फाइल डाउनलोड करणे, इन-ॲप ब्राउझरमध्ये वेबसाइट उघडणे, ऑपरेटिंग सिस्टम शेअरिंग मेनूद्वारे फाइल शेअर करणे किंवा ईमेलद्वारे सपोर्ट टीमशी संपर्क साधणे. त्या बाह्य सेवा तुमचा आयपी पत्ता, विनंती केलेली URL किंवा शेअर केलेली सामग्री यासारखा तांत्रिक डेटा प्राप्त करू शकतात. त्या सेवांची स्वतःची स्वतंत्र गोपनीयता धोरणे लागू होतात. Docs चा त्या बाह्य सेवांवर कोणताही ताबा किंवा जबाबदारी नाही.

6. डेटा नियंत्रण आणि संपर्क माहिती

तुम्ही Docs आणि तुमच्या डिव्हाइसची अंगभूत फाइल टूल्स वापरून कधीही तुमचे दस्तऐवज व्यवस्थापित, संपादित किंवा हटवू शकता. ॲप डेटा साफ केल्याने स्थानिक शोध निर्देशांक आणि डायग्नोस्टिक्स पूर्णपणे हटवले जातात; परंतु यामुळे तुमच्या डिव्हाइसवरील इतर फोल्डरमध्ये जतन केलेले तुमचे दस्तऐवज हटवले जात नाहीत. गोपनीयतेविषयी प्रश्नांसाठी, कृपया ईमेलद्वारे संपर्क साधा: mohanmrks@yandex.com.
