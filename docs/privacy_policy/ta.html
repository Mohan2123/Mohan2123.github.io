தனியுரிமைக் கொள்கை

Docs

1. இந்தக் கொள்கை பற்றி

இந்த தனியுரிமைக் கொள்கையானது, Mohan MRKS உருவாக்கிய Docs செயலி ("Docs" அல்லது "செயலி") நீங்கள் பயன்படுத்தும்போது உங்கள் தகவல்களை எவ்வாறு கையாளுகிறது மற்றும் பாதுகாக்கிறது என்பதை விரிவாக விளக்குகிறது. Docs உங்கள் சாதனத்தின் நினைவகத்தில் உள்ள ஆவணங்களை உள்ளூரில் நிர்வகிக்கவும் திருத்தவும் பிரத்யேகமாக வடிவமைக்கப்பட்டுள்ளது. இந்த செயலி டெவலப்பரால் இயக்கப்படும் ஆன்லைன் பயனர் கணக்கையோ அல்லது கிளவுட் அடிப்படையிலான ஆவண ஒத்திசைவு சேவையையோ வழங்குவதில்லை.

2. ஆவணங்கள் மற்றும் உள்ளூர் குறியீடு

உங்கள் ஆவணங்கள் உங்கள் சாதனத்தில் அல்லது நீங்கள் தேர்ந்தெடுக்கும் இடங்களில் மட்டுமே படிக்கப்படுகின்றன, திருத்தப்படுகின்றன மற்றும் சேமிக்கப்படுகின்றன. Docs உங்கள் ஆவணங்களின் உள்ளடக்கத்தை எந்தவொரு சர்வர்க்கும் ஒருபோதும் அனுப்புவதில்லை. கோப்புகளைப் பட்டியலிட, உடனடியாகத் தேட மற்றும் நேர்த்தியாக ஒழுங்கமைக்க, செயலி உங்கள் சாதனத்தில் ஒரு உள்ளூர் தரவுத்தளத்தை பராமரிக்கிறது, இதில் கோப்பு பாதைகள், பெயர்கள், நீட்டிப்புகள், அளவுகள், மாற்றியமைக்கப்பட்ட நேரங்கள், விருப்பமான மற்றும் பாதுகாக்கப்பட்ட நிலை, மற்றும் விரைவான தேடலுக்காக பிரித்தெடுக்கப்பட்ட உரை மாதிரிகள் ஆகியவை இருக்கும். இந்தத் தரவுத்தளம் மற்றும் மாதிரிகள் உங்கள் சாதனத்தில் மட்டுமே இருக்கும், மேலும் செயலியின் தரவு அழிக்கப்படும்போது அல்லது செயலி நீக்கப்படும்போது முற்றிலும் அகற்றப்படும்; செயலியின் தனிப்பட்ட சேமிப்பகத்திற்கு வெளியே சேமிக்கப்பட்ட கோப்புகள் உங்கள் சாதனத்தில் பாதுகாப்பாக இருக்கும்.

Android இயங்குதளத்தில், ஆவணங்களைக் கண்டறிந்து நிர்வகிக்க, ஆதரிக்கப்படும் Android பதிப்புகளில் "அனைத்து கோப்புகளுக்கான அணுகல்" (All-Files Access) உட்பட சேமிப்பக அணுகல் அனுமதியை Docs கோரலாம். பிற இயங்குதளங்களில், அந்தந்த தளத்தின் இயல்புநிலை கோப்புத் தேர்வு மற்றும் சேமிப்பக வழிமுறைகள் மூலம் அணுகல் வழங்கப்படுகிறது.

3. கடவுச்சொல் பாதுகாக்கப்பட்ட ஆவணங்கள்

நீங்கள் "பாதுகாத்துச் சேமி" என்ற அம்சத்தைத் தேர்ந்தெடுக்கும்போது, Docs உங்கள் கடவுச்சொல்லில் இருந்து PBKDF2-HMAC-SHA-256 மூலம் பெறப்பட்ட குறியாக்க விசையுடன் வலுவான AES-256-GCM தரநிலையைப் பயன்படுத்தி ஆவணத்தை முழுமையாகக் குறியாக்கம் செய்கிறது. இந்த கடவுச்சொல் டெவலப்பருக்கு ஒருபோதும் பதிவேற்றப்படுவதில்லை அல்லது சேமிக்கப்படுவதில்லை. உங்கள் கடவுச்சொல்லை பாதுகாப்பான இடத்தில் வைக்கவும்: மறந்த கடவுச்சொல்லை டெவலப்பரால் எந்த வகையிலும் மீட்டெடுக்க முடியாது, மேலும் அதை இழப்பது பாதுகாக்கப்பட்ட கோப்பை நிரந்தரமாக அணுக முடியாமல் செய்துவிடும்.

4. பிழை கண்டறிதல் மற்றும் அறிக்கைகள்

தொழில்நுட்ப சிக்கல்களைத் தீர்ப்பதற்கும் நிலைத்தன்மையை மேம்படுத்துவதற்கும், Docs செயலியின் தனிப்பட்ட உள்ளூர் சேமிப்பகத்தில் உள்ள ஒரு கண்டறிதல் பதிவுக் கோப்பில் பிழை விவரங்களை (பிழைச் செய்திகள் போன்றவை) பதிவு செய்கிறது. இந்த கண்டறிதல் அறிக்கைகள் Docs ஆல் தானாக நெட்வொர்க் வழியாக அனுப்பப்படுவதில்லை. கோப்பின் அளவு அதிகரிக்கும்போது உள்ளூரில் சுழற்சி முறையில் புதுப்பிக்கப்படும். பிழை விவரங்களில் சூழல் தகவல்கள் இருக்கலாம் என்பதால், நீங்கள் முழுமையாக ஆய்வு செய்யாமல் பிறருடன் பகிர்வதைத் தவிர்க்கவும்.

5. நெட்வொர்க் மற்றும் மூன்றாம் தரப்பு சேவைகள்

நீங்கள் மேற்கொள்ளும் சில குறிப்பிட்ட நடவடிக்கைகள் Docs-க்கு வெளியேயான வெளிப்புற சேவைகளுடன் தொடர்பு கொள்ளலாம்; ஒரு URL-லிருந்து கோப்பைப் பதிவிறக்குவது, பயன்பாட்டிலுள்ள உலாவியில் ஒரு வலைத்தளத்தைத் திறப்பது, கணினி பகிர்வு மெனு வழியாக கோப்பைப் பகிர்வது அல்லது மின்னஞ்சல் மூலம் ஆதரவைத் தொடர்புகொள்வது ஆகியவை இதில் அடங்கும். அந்த வெளிப்புற சேவைகள் உங்கள் IP முகவரி அல்லது நீங்கள் பகிரும் உள்ளடக்கம் போன்ற தொழில்நுட்பத் தகவல்களைப் பெறக்கூடும். அந்தந்த மூன்றாம் தரப்பு சேவைகளின் சொந்தக் கொள்கைகளே இதற்குப் பொருந்தும். அத்தகைய சேவைகளின் மீது Docs-க்கு எந்தக் கட்டுப்பாடும் பொறுப்பும் இல்லை.

6. தரவுக் கட்டுப்பாடு மற்றும் தொடர்பு விவரங்கள்

Docs செயலி மற்றும் உங்கள் சாதனத்தின் கோப்புக் கருவிகளைப் பயன்படுத்தி எந்த நேரத்திலும் உங்கள் ஆவணங்களை நிர்வகிக்கலாம், திருத்தலாம் அல்லது நீக்கலாம். செயலித் தரவை அழிப்பது உள்ளூர் தேடல் குறியீட்டை அகற்றும்; ஆனால் உங்கள் சாதனத்தின் பிற கோப்புறைகளில் உள்ள ஆவணங்களை இது அழிக்காது. தனியுரிமை தொடர்பான கேள்விகளுக்கு, மின்னஞ்சல் மூலம் எங்களைத் தொடர்பு கொள்ளவும்: mohanmrks@yandex.com.

7. கொள்கை மாற்றங்கள்

Docs செயலி மேம்படுத்தப்படும்போது இந்தக் கொள்கை புதுப்பிக்கப்படலாம். இந்தக் கொள்கை அவ்வப்போது மறுஆய்வு செய்யப்படலாம்.
