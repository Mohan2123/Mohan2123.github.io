Datenschutzerklärung

Docs

1. Über diese Richtlinie

Diese Datenschutzerklärung beschreibt ausführlich, wie die von Mohan MRKS entwickelte Anwendung Docs („Docs“ oder die „App“) Informationen verarbeitet, wenn Sie diese nutzen. Docs wurde speziell dafür entwickelt, auf Ihrem Endgerät gespeicherte Dokumente lokal zu verwalten und zu bearbeiten. Die App bietet weder ein vom Entwickler betriebenes Online-Benutzerkonto noch einen cloudbasierten Dokumentensynchronisierungsdienst an.

2. Dokumente und lokaler Index

Ihre Dokumente werden ausschließlich lokal auf Ihrem Endgerät oder an von Ihnen gewählten Speicherorten gelesen, bearbeitet und gespeichert. Docs sendet zu keinem Zeitpunkt Dokumenteninhalte an Server von Docs oder Dritte. Um Dateien aufzulisten, schnell zu durchsuchen und übersichtlich zu organisieren, führt die App eine lokale Datenbank auf dem Gerät, die Dateipfade, Dateinamen, Erweiterungen, Dateigrößen, Änderungsdaten, Favoriten- und Schutzstatus sowie für die Volltextsuche extrahierte Textvorschauen enthält. Diese Datenbank und ihre Vorschauen verbleiben vollständig auf Ihrem Gerät und werden gelöscht, wenn die Anwendungsdaten der App gelöscht oder die App deinstalliert wird; außerhalb des privaten App-Speichers abgelegte Dateien bleiben auf Ihrem Gerät erhalten.

Unter Android kann Docs den Speicherzugriff anfordern (einschließlich des Zugriffs auf alle Dateien unter unterstützten Android-Versionen), um Dokumente auf dem Gerät aufzufinden und zu verwalten. Auf anderen Plattformen erfolgt der Dateizugriff über die standardmäßigen Dateiauswahl- und Speicherdialoge des jeweiligen Betriebssystems.

3. Passwortgeschützte Dokumente

Wenn Sie die Funktion „Schützen & Speichern“ wählen, verschlüsselt Docs das exportierte Dokument mit dem anerkannten Sicherheitsstandard AES-256-GCM und einem Schlüssel, der mittels PBKDF2-HMAC-SHA-256 aus Ihrem Passwort abgeleitet wird. Dieses Passwort wird zu keinem Zeitpunkt an den Entwickler übertragen oder auf Servern gespeichert. Bewahren Sie Ihr Passwort sorgfältig und sicher auf: Ein vergessenes Passwort kann vom Entwickler nicht wiederhergestellt werden, und ein Verlust führt dazu, dass die geschützte Datei dauerhaft unzugänglich wird.

4. Diagnose und Fehlerberichte

Zur technischen Fehlerbehebung und Stabilitätsverbesserung protokolliert Docs Anwendungsfehlerdetails wie Fehlermeldungen und Stack-Traces in einer Diagnosedatei im privaten lokalen Speicher der App. Diese Berichte werden von Docs niemals automatisch über das Netzwerk übertragen. Die Diagnosedatei wird lokal rolliert, sobald sie eine bestimmte Größe erreicht. Da Fehlerdetails kontextbezogene Informationen enthalten können, sollten Diagnosedateien nicht ohne vorherige Überprüfung weitergegeben werden.

5. Netzwerk und Dienste von Drittanbietern

Bestimmte Aktionen, die Sie aktiv initiieren, können mit externen Diensten kommunizieren. Dazu gehören das Herunterladen einer Datei über eine URL, das Öffnen einer Website im integrierten In-App-Browser, das Teilen einer Datei über das Teilen-Menü des Betriebssystems oder die Kontaktaufnahme mit dem Kundensupport per E-Mail. Diese externen Dienste können technische Daten wie Ihre IP-Adresse, die angeforderte URL oder die von Ihnen geteilten Inhalte empfangen. Für diese Dienste gelten deren jeweilige eigene Datenschutzrichtlinien. Docs hat keinerlei Einfluss auf oder Kontrolle über diese Drittanbieterdienste.

6. Ihre Datenrechte und Kontaktmöglichkeiten

Sie können Ihre Dokumente jederzeit über Docs sowie über die Dateimanager-Tools Ihres Geräts eigenverantwortlich verwalten, bearbeiten oder löschen. Durch das Löschen der Anwendungsdaten der App werden deren lokaler Index und die Diagnosedateien vollständig entfernt; dies löscht jedoch nicht zwingend Ihre an anderen Orten auf dem Gerät gespeicherten Dokumente. Bei Fragen zum Datenschutz kontaktieren Sie uns bitte per E-Mail unter: mohanmrks@yandex.com.

7. Änderungen dieser Richtlinie

Diese Datenschutzerklärung kann von Zeit zu Zeit aktualisiert werden, sobald Docs weiterentwickelt wird oder neue Funktionen hinzukommen. Diese Richtlinie kann regelmäßig überprüft werden.
