2. Архитектура обработки данных и политика локального хранения

Диспетчер файлов спроектирован преимущественно как автономный инструмент, предназначенный для управления локальным хранилищем, просмотра файлов, архивации, воспроизведения мультимедиа, редактирования документов и биометрической защиты файлов. Основные функции Приложения выполняются локально на вашем клиентском устройстве.

  • Локальные данные файлов: Вся индексация файлов, создание метаданных каталогов, генерация миниатюр, воспроизведение мультимедиа, обработка архивов (архивов (ZIP, TAR, RAR, 7Z)) и редактирование кода происходят локально на вашем устройстве. Мы не передаем, не копируем и не сохраняем ваши личные файлы, фотографии, видео, аудиозаписи или документы на внешние облачные серверы, управляемые нами.
  • Биометрические данные и шифрование: Аутентификация в защищенных папках осуществляется с использованием системных API биометрии Android (Биометрическая аутентификация Android) и локальных криптографических алгоритмов. Ваши биометрические данные (отпечатки пальцев, сканы лица) обрабатываются исключительно изолированной средой безопасности вашего устройства. Мы никогда не получаем доступ, не храним и не передаем ваши биометрические идентификаторы.
  • База данных приложения: Локальное состояние приложения, теги, пользовательские категории, избранное и настройки хранятся локально в изолированной песочнице базы данных SQLite с использованием движка База данных SQLite на вашем устройстве.

3. Разрешения устройства и их назначение

Для обеспечения полной функциональности навигации и работы с файлами Приложение запрашивает системные разрешения и разрешения времени выполнения. Ниже подробно описано, для чего используется каждое разрешение:

  • Управление внешним накопителем (MANAGE_EXTERNAL_STORAGE) / Чтение внешнего накопителя (READ_EXTERNAL_STORAGE) / Запись на внешний накопитель (WRITE_EXTERNAL_STORAGE): Предоставляется для выполнения полного спектра файловых операций в общем хранилище устройства, включая создание, переименование, удаление, копирование, перемещение, архивацию и редактирование документов и мультимедийных файлов.
  • Чтение изображений (READ_MEDIA_IMAGES) / Чтение видео (READ_MEDIA_VIDEO) / Чтение аудиозаписей (READ_MEDIA_AUDIO): Требуется на Android 13 и новее для фильтрации, организации, отображения миниатюр и воспроизведения медиафайлов, сохраненных в локальном хранилище вашего устройства.
  • Камера (CAMERA): Используется исключительно в том случае, если вы используете сканер документов или встроенную функцию камеры в Приложении для съемки фотографий непосредственно в выбранные целевые папки.
  • Использование биометрии (USE_BIOMETRIC) / Использование отпечатка пальца (USE_FINGERPRINT): Требуется для аутентификации личности пользователя перед разблокировкой защищенных или скрытых папок в Приложении.
  • Запрос списка приложений (QUERY_ALL_PACKAGES) / Запрос удаления приложений (REQUEST_DELETE_PACKAGES) / Статистика использования приложений: Используется для инструментов диспетчера приложений, позволяя просматривать использование памяти установленными приложениями, создавать резервные копии файлов файлов APK или запускать удаление пакетов по прямому запросу.
  • Точное местоположение (ACCESS_FINE_LOCATION) / Приблизительное местоположение (ACCESS_COARSE_LOCATION) / Устройства Wi-Fi поблизости (NEARBY_WIFI_DEVICES) / Состояние Wi-Fi (ACCESS_WIFI_STATE) / Изменение состояния Wi-Fi (CHANGE_WIFI_STATE) / Изменение состояния сети (CHANGE_NETWORK_STATE): Запрашивается исключительно для обеспечения высокоскоростной прямой передачи файлов между устройствами (между устройствами) по Wi-Fi Direct или через локальную точку доступа Wi-Fi. Службы геолокации требуются операционной системой Android для сканирования близлежащих устройств Wi-Fi. Данные о местоположении никогда не записываются, не сохраняются и не передаются на какие-либо серверы.
  • Отправка уведомлений (POST_NOTIFICATIONS) / Работа в переднем плане (FOREGROUND_SERVICE): Используется для отображения непрерывных уведомлений о состоянии во время фоновых операций, таких как текущая передача файлов, пакетное сжатие/распаковка или очистка хранилища.

4. Сторонняя реклама и сбор аналитических данных

В Приложение интегрирован сервис Google AdMob (предоставляемый компанией Google LLC) для показа рекламы. Хотя мы не собираем персональные данные напрямую, Google AdMob может автоматически собирать и обрабатывать определенные телеметрические данные через Google Mobile Ads для персонализации рекламы, аналитики, отчетности и предотвращения мошенничества.

Типы данных, собираемых Google AdMob:

  • Идентификаторы устройств: Рекламный идентификатор (например, Рекламный идентификатор Google), IP-адрес, модель оборудования, версия операционной системы и язык системы.
  • Данные об использовании и производительности приложения: Журналы взаимодействия с рекламой, метрики показов, отслеживание кликов, отчеты о сбоях и диагностика приложения.
  • Приблизительные данные о местоположении: Неточное местоположение, определяемое по IP-адресу для показа геотаргетированной рекламы.

В зависимости от вашей юрисдикции вы обладаете определенными законными правами в отношении вашей личной информации в соответствии с действующими международными законами о конфиденциальности, включая Общий регламент ЕС по защите данных, Закон Калифорнии о конфиденциальности потребителей, Закон Бразилии о защите персональных данных и Закон Индии о защите цифровых персональных данных:

  • Право на доступ и контроль: Поскольку данные ваших файлов хранятся исключительно на вашем локальном устройстве, вы сохраняете 100% контроль над ними. Вы можете просматривать, изменять, экспортировать или удалять любой файл в любое время непосредственно через Приложение или системный файловый менеджер.
  • Право на отказ от персонализированной рекламы: Вы можете в любое время сбросить или отключить свой рекламный идентификатор в настройках устройства (перейдите в Настройки > Google > Реклама > Сбросить рекламный идентификатор / Удалить рекламный идентификатор).
  • Хранение и удаление данных: При удалении Приложения с вашего устройства безвозвратно удаляются все записи изолированной локальной базы данных, кэш приложения и сохраненные параметры конфигурации. Файлы, созданные в общем хранилище, остаются под управлением пользователя.

Наше Приложение не предназначено для детей младше 13 лет (или младше 16 лет в некоторых европейских юрисдикциях). Мы сознательно не запрашиваем и не собираем персональные данные детей. Сервис Google AdMob настроен в соответствии с требованиями закона COPPA и применимыми стандартами безопасности детей. Если нам станет известно, что персональные данные несовершеннолетнего были собраны без проверяемого согласия родителей, мы примем незамедлительные меры для удаления или ограничения такой информации.

Мы применяем стандартные отраслевые меры безопасности. Локальное хранилище приложения и подключения к базе данных защищены с помощью стандартной изоляции контроля доступа платформы (песочницы).
