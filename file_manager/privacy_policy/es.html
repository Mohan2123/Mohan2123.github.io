1. Arquitectura de privacidad ante todo

Esta Política de Privacidad se aplica a la aplicación móvil File Manager ("Aplicación", "Servicio"), desarrollada por Mohan MRKS ("Desarrollador"). File Manager está diseñada con un enfoque de "Privacidad ante todo".

2. Política de manejo de datos y permisos

File Manager funciona localmente en su dispositivo como una utilidad sin conexión. Detalles de permisos:

  • MANAGE_EXTERNAL_STORAGE / READ_EXTERNAL_STORAGE: Otorgado localmente en su dispositivo para abrir, leer, editar y guardar archivos. Sus archivos personales nunca se cargan en ningún servidor externo.
  • CAMERA: Otorgado localmente para capturar fotos o escanear códigos. Los fotogramas de la cámara se procesan en la memoria.
  • POST_NOTIFICATIONS: Otorgado para mostrar controles de reproducción o actualizaciones de estado en segundo plano.

3. Garantía de procesamiento local y sin conexión

Todas las operaciones y procesamiento principal de File Manager se ejecutan 100% localmente en el hardware del cliente.

4. Publicidad de terceros y datos de telemetría

La Aplicación integra Google AdMob (proporcionado por Google LLC) para mostrar anuncios. Google AdMob puede procesar identificadores de dispositivos para la entrega de anuncios y prevención de fraudes.

5. Privacidad infantil (Cumplimiento de COPPA)

La Aplicación no recopila a sabiendas datos personales de niños menores de 13 años. Google AdMob está configurado para cumplir con las directrices de COPPA.
