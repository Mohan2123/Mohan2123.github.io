1. Pendahuluan

Kebijakan Privasi ini berlaku untuk aplikasi seluler File Manager ("Aplikasi", "App", "Layanan"), yang dikembangkan oleh Mohan RKS ("Pengembang", "Kami"). Kami menghormati privasi Anda dan berkomitmen untuk melindunginya melalui kepatuhan terhadap kebijakan ini. Kebijakan ini menjelaskan jenis informasi yang dapat kami kumpulkan dari Anda atau yang Anda berikan saat mengunduh, memasang, mendaftar, mengakses, atau menggunakan Aplikasi, serta praktik kami dalam mengumpulkan, menggunakan, memelihara, melindungi, dan mengungkapkan informasi tersebut.

Harap baca kebijakan ini dengan saksama untuk memahami kebijakan dan praktik kami terkait informasi Anda dan bagaimana kami akan memperlakukannya. Jika Anda tidak menyetujui kebijakan dan praktik kami, pilihan Anda adalah tidak mengunduh, memasang, atau menggunakan Aplikasi ini. Dengan mengunduh, memasang, atau menggunakan Aplikasi ini, Anda menyetujui Kebijakan Privasi ini.

2. Arsitektur Penanganan Data & Kebijakan Penyimpanan Lokal

File Manager dirancang terutama sebagai alat mandiri luring yang didedikasikan untuk manajemen penyimpanan lokal, penjelajahan file, pengarsipan, pemutaran media, pengeditan dokumen, dan keamanan file biometrik. Fitur inti dari Aplikasi beroperasi secara lokal di perangkat klien Anda.

  • Data File Lokal: Semua pengindeksan file, pembuatan metadata direktori, pembuatan gambar mini, rendering media, manipulasi arsip (ZIP, TAR, RAR, 7Z), dan pengeditan kode terjadi secara lokal di perangkat Anda. Kami tidak mentransfer, mencerminkan, atau mencadangkan file pribadi, foto, video, audio, atau dokumen Anda ke server cloud eksternal yang kami operasikan.
  • Kredensial Biometrik & Enkripsi: Autentikasi folder aman bergantung pada API Biometrik Sistem Android dan primitif kriptografi lokal. Data biometrik Anda (sidik jari, metrik wajah) diproses secara eksklusif oleh Secure Enclave / Trusted Execution Environment perangkat Anda. Kami tidak pernah mengakses, menyimpan, atau mengirimkan pengidentifikasi biometrik Anda.
  • Basis Data Aplikasi: Status aplikasi lokal, tag, kategorisasi khusus, favorit, dan pengaturan disimpan secara lokal di basis data SQLite terisolasi melalui mesin Basis Data Lokal SQLite di perangkat Anda.

3. Izin Perangkat & Rincian Tujuan

Untuk menyediakan fungsionalitas navigasi dan eksekusi file yang lengkap, Aplikasi meminta izin runtime dan sistem. Berikut adalah rincian tentang bagaimana setiap izin digunakan:

  • Pengelolaan Penyimpanan Eksternal (MANAGE_EXTERNAL_STORAGE) / Membaca Penyimpanan Eksternal (READ_EXTERNAL_STORAGE) / Menulis Penyimpanan Eksternal (WRITE_EXTERNAL_STORAGE): Diberikan untuk memungkinkan operasi file penuh di seluruh penyimpanan perangkat bersama, termasuk membuat, mengganti nama, menghapus, menyalin, memindahkan, mengarsipkan, dan mengedit dokumen serta file media.
  • Membaca Gambar (READ_MEDIA_IMAGES) / Membaca Video (READ_MEDIA_VIDEO) / Membaca Audio (READ_MEDIA_AUDIO): Diperlukan di Android 13+ untuk memfilter, mengatur, menampilkan thumbnail, dan memutar file media yang disimpan di penyimpanan lokal perangkat Anda.
  • Kamera (CAMERA): Digunakan semata-mata jika Anda menggunakan pemindai dokumen atau fitur pengambilan kamera bawaan dalam Aplikasi untuk mengambil foto langsung ke folder tujuan tertentu.
  • Penggunaan Biometrik (USE_BIOMETRIC) / Penggunaan Sidik Jari (USE_FINGERPRINT): Diperlukan untuk mengautentikasi identitas pengguna sebelum membuka kunci folder yang dilindungi atau disembunyikan di dalam Aplikasi.
  • Kueri Semua Paket (QUERY_ALL_PACKAGES) / Permintaan Hapus Paket (REQUEST_DELETE_PACKAGES) / Statistik Penggunaan Paket: Digunakan untuk utilitas pengelola aplikasi, memungkinkan Anda melihat penggunaan penyimpanan aplikasi yang terpasang, mencadangkan file APK, atau memicu pencopotan pemasangan paket atas permintaan eksplisit.
  • Lokasi Presisi (ACCESS_FINE_LOCATION) / Lokasi Perkiraan (ACCESS_COARSE_LOCATION) / Perangkat Wi-Fi Sekitar (NEARBY_WIFI_DEVICES) / Status Wi-Fi (ACCESS_WIFI_STATE) / Ubah Status Wi-Fi (CHANGE_WIFI_STATE) / Ubah Status Jaringan (CHANGE_NETWORK_STATE): Diminta secara eksklusif untuk mengaktifkan transfer file peer-to-peer langsung berkecepatan tinggi melalui Koneksi Wi-Fi Langsung atau jaringan Hotspot Wi-Fi lokal. Layanan lokasi diperlukan oleh sistem operasi Android untuk memindai perangkat Wi-Fi terdekat. Data lokasi tidak pernah direkam, disimpan, atau dikirimkan ke server mana pun.
  • Kirim Notifikasi (POST_NOTIFICATIONS) / Layanan Latar Depan (FOREGROUND_SERVICE): Digunakan untuk menampilkan pembaruan status persisten selama operasi di latar belakang, seperti transfer file yang sedang berlangsung, kompresi/ekstraksi batch, atau tugas pembersihan penyimpanan.

4. Iklan Pihak Ketiga & Pengumpulan Data Analitik

Aplikasi mengintegrasikan Google AdMob untuk menayangkan iklan. Meskipun kami tidak mengumpulkan data pribadi secara langsung, Google AdMob dapat mengumpulkan dan memproses data telemetri tertentu secara otomatis melalui Google Mobile Ads SDK untuk personalisasi iklan, analitik, pelaporan, dan pencegahan penipuan.

Jenis Data yang Dikumpulkan oleh Google AdMob:

  • Pengenal Perangkat: ID Iklan (misalnya, Google AAID), alamat IP, model perangkat keras, versi sistem operasi, dan bahasa sistem.
  • Data Penggunaan & Kinerja Aplikasi: Log interaksi iklan, metrik tayangan, pelacakan klik, laporan kerusakan, dan diagnostik aplikasi.
  • Data Lokasi Perkiraan: Lokasi tidak presisi yang disimpulkan dari alamat IP untuk penargetan iklan berbasis wilayah geografis.

Untuk informasi lebih rinci mengenai praktik penanganan data Google, silakan merujuk ke:

  • Cara Google menggunakan informasi dari situs atau aplikasi yang menggunakan layanan kami
  • Kebijakan Privasi & Persyaratan Google

5. Perlindungan Data Pengguna & Hak Peraturan Global

Tergantung pada yurisdiksi Anda, Anda memiliki hak hukum khusus mengenai informasi pribadi Anda berdasarkan undang-undang privasi global yang berlaku, termasuk Peraturan Perlindungan Data Umum Uni Eropa, Undang-Undang Privasi Konsumen California, Undang-Undang Perlindungan Data Umum Brasil, dan Undang-Undang Perlindungan Data Pribadi Digital India:

  • Hak Akses & Kontrol: Karena data file Anda tetap berada secara eksklusif di perangkat lokal Anda, Anda memegang kendali 100% atas data Anda. Anda dapat memeriksa, memodifikasi, mengekspor, atau menghapus file apa pun kapan saja secara langsung melalui Aplikasi atau pengelola file sistem.
  • Hak untuk Menolak Iklan yang Dipersonalisasi: Anda dapat mengatur ulang atau menonaktifkan ID Iklan Anda kapan saja melalui pengaturan perangkat Anda (Buka Pengaturan > Google > Iklan > Hapus ID Iklan atau Pilih tidak ikut Personalisasi Iklan).
  • Retensi & Penghapusan Data: Mencopot pemasangan Aplikasi akan menghapus secara permanen semua catatan basis data lokal terisolasi, cache aplikasi, dan pengaturan konfigurasi yang tersimpan dari perangkat Anda. File yang dibuat di penyimpanan bersama umum tetap berada di bawah kendali pengguna.

6. Perlindungan Privasi Daring Anak-anak

Aplikasi kami tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak secara sengaja meminta atau mengumpulkan data pribadi dari anak-anak. Google AdMob dikonfigurasikan untuk mematuhi COPPA dan kerangka kerja keselamatan anak yang relevan. Jika kami mengetahui bahwa data pribadi anak di bawah umur telah dikumpulkan tanpa persetujuan orang tua yang dapat diverifikasi, kami akan segera mengambil langkah untuk menghapus atau membatasi informasi tersebut.

7. Perlindungan Keamanan Data

Kami menerapkan praktik keamanan standar industri. Penyimpanan aplikasi lokal dan koneksi basis data diamankan menggunakan kontrol akses isolasi standar platform. Tindakan sensitif, seperti akses ke brankas penyimpanan yang dilindungi, memerlukan verifikasi biometrik yang didukung perangkat keras. Namun, tidak ada metode penyimpanan elektronik atau transmisi melalui jaringan nirkabel yang 100% aman; kami mengimbau pengguna untuk menjaga kode sandi perangkat yang kuat dan enkripsi perangkat tetap aktif.

8. Transfer Data Internasional

Karena fungsi inti aplikasi beroperasi secara offline, tidak ada konten file yang ditransfer melintasi batas negara oleh kami. Data telemetri AdMob SDK dapat diproses di server yang berlokasi di Amerika Serikat atau negara lain tempat Google mengoperasikan infrastruktur, tunduk pada klausul kontrak standar dan kerangka kerja privasi global yang ketat.
