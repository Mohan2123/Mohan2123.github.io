1. Introdução

Esta Política de Privacidade aplica-se ao aplicativo móvel File Manager ("Aplicativo", "App", "Serviço"), desenvolvido por Mohan RKS ("Desenvolvedor", "Nós", "Nosso"). Respeitamos sua privacidade e temos o compromisso de protegê-la em conformidade com esta política. Esta política descreve os tipos de informações que podemos coletar de você ou que você pode fornecer ao baixar, instalar, registrar-se, acessar ou usar o Aplicativo, bem como nossas práticas de coleta, uso, manutenção, proteção e divulgação dessas informações.

Leia esta política com atenção para entender nossas práticas relativas às suas informações e como as trataremos. Se você não concordar com nossas políticas e práticas, sua opção é não baixar, instalar ou usar este Aplicativo. Ao baixar, instalar ou usar este Aplicativo, você concorda com esta Política de Privacidade.

2. Arquitetura de Tratamento de Dados e Política de Armazenamento Local

O File Manager foi projetado principalmente como uma ferramenta independente offline dedicada ao gerenciamento de armazenamento local, navegação de arquivos, compactação/arquivamento, reprodução de mídia, edição de documentos e segurança biométrica de arquivos. Os recursos fundamentais do Aplicativo operam localmente em seu dispositivo.

  • Dados de Arquivos Locais: Toda a indexação de arquivos, criação de metadados de diretórios, geração de miniaturas, renderização de mídia, manipulação de arquivos compactados (ZIP, TAR, RAR, 7Z) e edição de código ocorrem localmente em seu dispositivo. Nós não transferimos, espelhamos ou fazemos backup de seus arquivos pessoais, fotos, vídeos, áudios ou documentos para servidores em nuvem externos operados por nós.
  • Credenciais Biométricas e Criptografia: A autenticação de pasta segura depende das APIs biométricas do sistema Android (Autenticação Biométrica do Sistema) e de primitivas criptográficas locais. Seus dados biométricos (impressões digitais, reconhecimento facial) são processados exclusivamente pelo Enclave Seguro / Ambiente de Execução Confiável do seu dispositivo. Nunca acessamos, armazenamos ou transmitimos seus identificadores biométricos.
  • Banco de Dados do Aplicativo: O estado local do aplicativo, tags, categorização personalizada, favoritos e configurações são armazenados localmente em um banco de dados SQLite isolado por meio do mecanismo Banco de Dados Local SQLite em seu dispositivo.

3. Permissões do Dispositivo e Detalhamento de Finalidades

Para fornecer funcionalidade completa de navegação e execução de arquivos, o Aplicativo solicita permissões de tempo de execução e de sistema. Abaixo está uma descrição detalhada de como cada permissão é utilizada:

  • Gerenciamento de Armazenamento Externo (MANAGE_EXTERNAL_STORAGE) / Leitura de Armazenamento Externo (READ_EXTERNAL_STORAGE) / Escrita em Armazenamento Externo (WRITE_EXTERNAL_STORAGE): Concedida para permitir operações completas de arquivos em todo o armazenamento compartilhado do dispositivo, incluindo criação, renomeação, exclusão, cópia, movimentação, compactação e edição de documentos e arquivos de mídia.
  • Leitura de Imagens (READ_MEDIA_IMAGES) / Leitura de Vídeos (READ_MEDIA_VIDEO) / Leitura de Áudio (READ_MEDIA_AUDIO): Necessária no Android 13+ para filtrar, organizar, renderizar miniaturas e reproduzir arquivos de mídia armazenados no armazenamento local do seu dispositivo.
  • Câmera (CAMERA): Utilizada exclusivamente se você usar o scanner de documentos ou os recursos integrados de captura de câmera no Aplicativo para tirar fotos diretamente em pastas de destino específicas.
  • Uso de Biometria (USE_BIOMETRIC) / Uso de Impressão Digital (USE_FINGERPRINT): Necessária para autenticar a identidade do usuário antes de desbloquear pastas protegidas ou ocultas no Aplicativo.
  • Consulta de Pacotes (QUERY_ALL_PACKAGES) / Solicitação de Exclusão de Pacotes (REQUEST_DELETE_PACKAGES) / Estatísticas de Uso de Aplicativos: Utilizada para utilitários do gerenciador de aplicativos, permitindo visualizar o uso de armazenamento dos aplicativos instalados, fazer backup de arquivos APK ou acionar a desinstalação de pacotes mediante solicitação explícita.
  • Localização Precisa (ACCESS_FINE_LOCATION) / Localização Aproximada (ACCESS_COARSE_LOCATION) / Dispositivos Wi-Fi Próximos (NEARBY_WIFI_DEVICES) / Estado do Wi-Fi (ACCESS_WIFI_STATE) / Alteração do Estado do Wi-Fi (CHANGE_WIFI_STATE) / Alteração do Estado da Rede (CHANGE_NETWORK_STATE): Solicitada exclusivamente para permitir transferências diretas de arquivos ponto a ponto de alta velocidade via Conexão Wi-Fi Direta ou redes de Hotspot Wi-Fi local. Os serviços de localização são exigidos pelo sistema operacional Android para buscar dispositivos Wi-Fi próximos. Os dados de localização nunca são registrados, armazenados ou transmitidos a nenhum servidor.
  • Envio de Notificações (POST_NOTIFICATIONS) / Serviço em Primeiro Plano (FOREGROUND_SERVICE): Utilizada para exibir atualizações de status contínuas durante operações em segundo plano, como transferências de arquivos em andamento, compactação/extração em lote ou tarefas de limpeza de armazenamento.

4. Publicidade de Terceiros e Coleta de Dados Analíticos

O Aplicativo integra o Google AdMob para veicular anúncios. Embora não coletemos dados pessoais diretamente, o Google AdMob pode coletar e processar determinados dados de telemetria automaticamente por meio do SDK do Google Mobile Ads para personalização de anúncios, análises, relatórios e prevenção contra fraudes.

Tipos de Dados Coletados pelo Google AdMob:

  • Identificadores de Dispositivo: ID de publicidade (ex.: Google AAID), endereço IP, modelo de hardware, versão do sistema operacional e idioma do sistema.
  • Dados de Uso e Desempenho do Aplicativo: Registros de interação com anúncios, métricas de impressões, rastreamento de cliques, relatórios de falhas e diagnósticos do aplicativo.
  • Dados de Localização Aproximada: Localização não precisa inferida a partir do endereço IP para publicidade com segmentação geográfica.

Para obter informações mais detalhadas sobre as práticas de tratamento de dados do Google, consulte:

  • Como o Google usa informações de sites ou apps que usam nossos serviços
  • Política de Privacidade e Termos do Google

5. Proteção de Dados do Usuário e Direitos Regulatórios Globais

Dependendo da sua jurisdição, você possui direitos estatutários específicos em relação às suas informações pessoais sob as leis de privacidade globais aplicáveis, incluindo o Regulamento Geral de Proteção de Dados da União Europeia, a Lei de Privacidade do Consumidor da Califórnia, a Lei Geral de Proteção de Dados do Brasil e a Lei de Proteção de Dados Pessoais Digitais da Índia:

  • Direito de Acesso e Controle: Como os dados de seus arquivos permanecem exclusivamente no seu dispositivo local, você mantém 100% de controle sobre eles. Você pode inspecionar, modificar, exportar ou excluir qualquer arquivo a qualquer momento diretamente pelo Aplicativo ou pelo gerenciador de arquivos do sistema.
  • Direito de Recusar Anúncios Personalizados: Você pode redefinir ou desativar seu ID de Publicidade a qualquer momento nas configurações do seu dispositivo (Acesse Configurações > Google > Anúncios > Excluir ID de publicidade ou Desativar personalização de anúncios).
  • Retenção e Exclusão de Dados: Desinstalar o Aplicativo remove permanentemente todos os registros do banco de dados local isolado, caches do app e definições de configuração armazenadas no dispositivo. Os arquivos criados no armazenamento compartilhado geral permanecem sob o controle do usuário.

6. Proteção da Privacidade Online das Crianças

Nosso Aplicativo não é direcionado a crianças menores de 13 anos (ou menores de 16 anos em determinadas jurisdições europeias). Não solicitamos ou coletamos intencionalmente dados pessoais de crianças. O Google AdMob está configurado para estar em conformidade com a COPPA e as normas de segurança infantil relevantes. Se tomarmos conhecimento de que dados pessoais de um menor foram coletados sem o consentimento parental verificável, tomaremos medidas imediatas para remover ou restringir tais informações.

7. Medidas de Segurança de Dados

Adotamos práticas de segurança que atendem aos padrões da indústria. O armazenamento do aplicativo local e as conexões de banco de dados são protegidos por isolamento de controle de acesso padrão da plataforma (ambiente isolado de segurançaing). Ações confidenciais, como o acesso a pastas de armazenamento protegidas, exigem verificação biométrica com suporte de hardware. No entanto, nenhum método de armazenamento eletrônico ou transmissão por redes sem fio é 100% seguro; incentivamos os usuários a manter senhas seguras e criptografia ativada no dispositivo.

8. Transferências Internacionais de Dados

Como as funções centrais do aplicativo operam offline, nenhum conteúdo de arquivo é transferido internacionalmente por nós. Os dados de telemetria do SDK do AdMob podem ser processados em servidores localizados nos Estados Unidos ou em outros países onde o Google mantém infraestrutura, em conformidade com cláusulas contratuais padrão e rigorosas diretrizes globais de privacidade.

9. Alterações e Atualizações da Política

Reservamo-nos o direito de modificar ou atualizar esta Política de Privacidade a qualquer momento. Quaisquer alterações serão publicadas diretamente nesta página com uma "Data de Vigência" atualizada. Recomendamos que os usuários revisem periodicamente esta política para se manterem informados sobre como protegemos sua privacidade.
