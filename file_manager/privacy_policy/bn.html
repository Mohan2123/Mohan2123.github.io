গোপনীয়তা নীতি

File Manager

1. গোপনীয়তা প্রথম স্থাপত্য

এই গোপনীয়তা নীতিটি Mohan MRKS ("বিকাশকারী") দ্বারা তৈরি File Manager মোবাইল অ্যাপ্লিকেশনের ক্ষেত্রে প্রযোজ্য। File Manager "গোপনীয়তা প্রথম" পদ্ধতির সাথে তৈরি করা হয়েছে।

2. ডেটা হ্যান্ডলিং এবং অনুমতি নীতি

File Manager আপনার ডিভাইসে একটি অফলাইন ইউটিলিটি হিসেবে স্থানীয়ভাবে কাজ করে। অনুমতির বিবরণ:

  • MANAGE_EXTERNAL_STORAGE / READ_EXTERNAL_STORAGE: ফাইল খোলা, পড়া, সম্পাদনা এবং সংরক্ষণ করার জন্য আপনার ডিভাইসে স্থানীয়ভাবে মঞ্জুর করা হয়েছে। আপনার ব্যক্তিগত ফাইল কখনোই কোনো বহিরাগত সার্ভারে আপলোড করা হয় না।
  • CAMERA: ছবি তোলার বা কোড স্ক্যান করার জন্য আপনার ডিভাইসে স্থানীয়ভাবে মঞ্জুর করা হয়েছে। ফ্রেমগুলি মেমরিতে প্রক্রিয়া করা হয়।
  • POST_NOTIFICATIONS: প্লেব্যাক নিয়ন্ত্রণ বা ব্যাকগ্রাউন্ড অপারেশন স্ট্যাটাস প্রদর্শনের জন্য মঞ্জুর করা হয়েছে।

3. অফলাইন এবং স্থানীয় প্রক্রিয়াকরণ গ্যারান্টি

File Manager-এর সমস্ত মূল প্রক্রিয়াকরণ এবং ক্রিয়াকলাপ ক্লায়েন্ট হার্ডওয়্যারে ১০০% স্থানীয়ভাবে সম্পন্ন হয়।

4. তৃতীয় পক্ষের বিজ্ঞাপন এবং টেলিমেট্রি ডেটা

এই অ্যাপ্লিকেশনটি বিজ্ঞাপন দেখানোর জন্য Google AdMob (Google LLC দ্বারা সরবরাহকৃত) ব্যবহার করে। Google AdMob বিজ্ঞাপন ডেলিভারি এবং জালিয়াতি প্রতিরোধের জন্য ডিভাইস শনাক্তকারী প্রক্রিয়া করতে পারে।

5. শিশুদের গোপনীয়তা (COPPA সম্মতি)

অ্যাপ্লিকেশনটি ১৩ বছরের কম বয়সী শিশুদের কাছ থেকে কোনো ব্যক্তিগত তথ্য সংগ্রহ করে না। Google AdMob শিশু সুরক্ষা নির্দেশিকা মেনে চলার জন্য কনফিগার করা হয়েছে।
