1. விதிமுறைகளை ஏற்றுக்கொள்வது

இந்த சேவை விதிமுறைகள் ("விதிமுறைகள்") Mohan MRKS ("டெவலப்பர்") உருவாக்கிய File Manager மொபைல் பயன்பாட்டின் உங்கள் பயன்பாட்டை நிர்வகிக்கிறது. பயன்பாட்டைப் பயன்படுத்துவதன் மூலம், இந்த விதிமுறைகளுக்குக் கட்டுப்பட ஒப்புக்கொள்கிறீர்கள்.

2. உரிமத்தின் நோக்கம் மற்றும் அனுமதிக்கப்பட்ட பயன்பாடு

உங்கள் சாதனத்தில் File Manager பயன்பாட்டைப் பயன்படுத்த வரையறுக்கப்பட்ட உரிமத்தை நாங்கள் உங்களுக்கு வழங்குகிறோம்.

3. உள்ளூர் தரவு மற்றும் பயனர் பொறுப்புகள்

உங்கள் சாதனத்தில் சேமிக்கப்பட்டுள்ள அனைத்து கோப்புகள் மற்றும் உள்ளடக்கங்களுக்கு நீங்களே முழுப் பொறுப்பு.

4. File Manager இன்ஜின் மறுப்பு

File Manager அம்சங்கள் எந்த உத்தரவாதமும் இன்றி "உள்ளபடியே" வழங்கப்படுகின்றன.

5. பொறுப்பு வரம்பு

சட்டத்தால் அனுமதிக்கப்பட்ட அதிகபட்ச வரம்பு வரை, பயன்பாட்டைப் பயன்படுத்துவதால் ஏற்படும் எந்தவொரு இழப்புக்கும் டெவலப்பர் பொறுப்பேற்க மாட்டார்.

6. கொள்கை புதுப்பிப்புகள் மற்றும் தொடர்பு தகவல்

இந்தக் கொள்கையை அவ்வப்போது புதுப்பிக்கும் உரிமையை நாங்கள் கொண்டுள்ளோம். உங்களுக்கு ஏதேனும் கேள்விகள் இருந்தால், தயவுசெய்து எங்களை தொடர்பு கொள்ளவும்:
