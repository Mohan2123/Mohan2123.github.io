File Manager

1. अटींची स्वीकृती

या सेवा अटी ("अटी") Mohan MRKS ("डेव्हलपर") द्वारे विकसित File Manager मोबाईल ॲप्लिकेशनच्या वापरावर नियंत्रण ठेवतात. ॲप वापरून, तुम्ही या अटींचे पालन करण्यास सहमती दर्शवता.

2. परवान्याची व्याप्ती आणि अनुमत वापर

आम्ही तुम्हाला तुमच्या डिव्हाइसवर File Manager वापरण्यासाठी मर्यादित, गैर-हस्तांतरणीय परवाना देतो.

3. स्थानिक डेटा आणि वापरकर्ता जबाबदाऱ्या

तुम्ही तुमच्या डिव्हाइसवर सेव्ह केलेल्या सर्व फाइल्स आणि डेटासाठी पूर्णपणे जबाबदार आहात.

4. File Manager इंजिन अस्वीकरण

File Manager ची वैशिष्ट्ये कोणत्याही वॉरंटीशिवाय "जशी आहेत तशी" प्रदान केली जातात.

5. दायित्व मर्यादा

कायद्याने परवानगी दिलेल्या कमाल मर्यादेपर्यंत, ॲपच्या वापरामुळे उद्भवणाऱ्या कोणत्याही नुकसानासाठी डेव्हलपर जबाबदार असणार नाही.

6. धोरण अद्यतने आणि संपर्क माहिती
