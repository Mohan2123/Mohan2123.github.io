File Manager

1. शर्तों की स्वीकृति

ये सेवा की शर्तें ("शर्तें") Mohan MRKS ("डेवलपर") द्वारा विकसित File Manager मोबाइल एप्लिकेशन ("एप्लिकेशन", "सेवा") के आपके उपयोग को नियंत्रित करती हैं। एप्लिकेशन का उपयोग करके, आप इन शर्तों से बंधे होने के लिए सहमत होते हैं।

2. लाइसेंस का दायरा और अनुमत उपयोग

हम आपको आपके मोबाइल डिवाइस पर File Manager का उपयोग करने के लिए एक सीमित, गैर-अनन्य, गैर-हस्तांतरणीय लाइसेंस प्रदान करते हैं।

3. स्थानीय डेटा और उपयोगकर्ता जिम्मेदारियाँ

आप अपने डिवाइस पर संग्रहीत सभी फ़ाइलों और सामग्री के लिए पूरी तरह जिम्मेदार हैं।

4. File Manager इंजन अस्वीकरण

File Manager की सुविधाएँ "जैसी हैं वैसी" स्थिति में बिना किसी वारंटी के प्रदान की जाती हैं।

5. देयता की सीमा

कानून द्वारा अनुमत अधिकतम सीमा तक, डेवलपर एप्लिकेशन के उपयोग से उत्पन्न होने वाले किसी भी अप्रत्यक्ष या परिणामी नुकसान के लिए उत्तरदायी नहीं होगा।
