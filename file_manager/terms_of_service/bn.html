1. শর্তাবলীর স্বীকৃতি

এই সেবার শর্তাবলী ("শর্তাবলী") Mohan MRKS ("বিকাশকারী") দ্বারা তৈরি File Manager মোবাইল অ্যাপ্লিকেশন ব্যবহারের ক্ষেত্রে প্রযোজ্য। অ্যাপ্লিকেশনটি ব্যবহার করে, আপনি এই শর্তাবলী মেনে চলতে সম্মত হন।

2. লাইসেন্সের সুযোগ এবং অনুমোদিত ব্যবহার

আমরা আপনাকে আপনার ডিভাইসে File Manager ব্যবহার করার জন্য একটি সীমিত, অ-হস্তান্তরযোগ্য লাইসেন্স প্রদান করি।

3. स्थानीय ডেটা এবং ব্যবহারকারীর দায়িত্ব

আপনি আপনার ডিভাইসে সংরক্ষিত সমস্ত ফাইল এবং সামগ্রীর জন্য এককভাবে দায়ী।

4. File Manager ইঞ্জিন দাবিত্যাগ

File Manager-এর বৈশিষ্ট্যগুলি কোনো ওয়ারেন্টি ছাড়াই "যেমন আছে" ভিত্তিতে প্রদান করা হয়।

5. দায়বদ্ধতার সীমাবদ্ধता

আইন দ্বারা অনুমোদিত সর্বোচ্চ সীমা পর্যন্ত, বিকাশকারী অ্যাপ্লিকেশন ব্যবহারের ফলে উদ্ভূত কোনো ক্ষতির জন্য দায়ী থাকবে না।

6. নীতি আপডেট এবং যোগাযোগের তথ্য

আমরা পর্যায়ক্রমে এই নীতি আপডেট করার অধিকার সংরক্ষণ করি। আপনার যদি কোনো প্রশ্ন থাকে, অনুগ্রহ করে আমাদের সাথে যোগাযোগ করুন:
