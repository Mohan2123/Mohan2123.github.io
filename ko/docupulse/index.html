DocuPulse 정보

영수증, 계약서, 신분증, 화이트보드를 테두리 감지, 그림자 제거, 오프라인 OCR 기능을 통해 선명한 PDF로 변환하는 포켓 스캐너.

주요 기능 및 성능

자동 문서 가장자리 감지

문서의 테두리를 자동으로 인식하고 기울기와 원근 왜곡을 완벽하게 보정합니다.

매직 필터

그림자를 말끔히 제거하고 대비를 높여 문서를 선명한 흑백 스캔으로 변환합니다.

오프라인 OCR 텍스트 추출

서버로 데이터를 전송하지 않고 50개 이상의 언어로 스캔 문서에서 텍스트를 안전하게 추출.

다중 페이지 일괄 스캔

책 한 권 분량이나 여러 페이지의 영수증, 청구서를 빠르게 연속 스캔하여 하나의 PDF로 병합.

신분증 및 여권 모드

신분증 앞뒷면을 차례로 스캔하여 표준 단일 페이지에 깔끔하게 합성합니다.
