노트 정보

중첩된 폴더, 생체 인식 잠금, 태그 및 첨부 파일이 포함된 깔끔하고 빠른 마크다운 메모와 서식 있는 텍스트 체크리스트입니다.

주요 기능 및 성능

리치 마크다운 편집기

헤더, 테이블, 체크리스트, 구문 강조 기능이 있는 코드 블록 및 수학 LaTeX.

생체 인식 메모 잠금

지문이나 PIN으로 기밀 메모를 개별적으로 보호하세요.

중첩된 폴더 및 태그

유연한 태그 지정을 통해 수천 가지 생각을 손쉽게 정리하세요.

인스턴트 검색

메모와 첨부 파일 전체에서 실시간 전체 텍스트 검색이 가능합니다.

내보내기 옵션

메모를 PDF, Markdown, HTML 또는 일반 텍스트로 내보냅니다.
