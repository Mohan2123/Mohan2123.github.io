Kebijakan Privasi

DocuPulse

1. Arsitektur Privasi Utama

Kebijakan Privasi ini berlaku untuk aplikasi seluler DocuPulse ("Aplikasi", "Layanan"), yang dikembangkan oleh Mohan MRKS ("Pengembang"). DocuPulse dirancang dengan prinsip ketat "Privasi Utama" dan pemrosesan penuh pada perangkat. Dokumen, pindaian, tanda tangan, dan file Anda sepenuhnya milik Anda.

2. Kebijakan Penanganan Data & Izin Perangkat

DocuPulse beroperasi secara lokal dan mandiri tanpa koneksi internet. Rincian izin yang diminta:

  • KAMERA: Digunakan secara eksklusif untuk mengambil gambar dokumen, kuitansi, dan catatan di antarmuka pemindai. Gambar diproses hanya dalam memori dan disimpan di penyimpanan aplikasi lokal perangkat, tidak pernah dikirim ke server luar.
  • AKSES PENYIMPANAN: Digunakan untuk mengimpor file foto atau PDF dan mengekspor dokumen yang telah selesai, arsip, dan tanda tangan ke folder pilihan Anda di perangkat. Tidak ada pengunggahan ke cloud.

3. Jaminan OCR dan Pemrosesan Lokal

Semua fitur utama DocuPulse — termasuk deteksi tepi otomatis, koreksi perspektif, filter gambar, pengenalan teks optik (OCR) di perangkat, tanda tangan digital, watermark, dan ekspor multi-format (PDF, JPEG, PNG, ZIP, dll.) — berjalan 100% secara lokal pada perangkat Anda.

4. Beroperasi Offline & Tanpa Pelacakan

DocuPulse tidak memuat SDK iklan pihak ketiga, analitik, telemetri, atau pelacak. Aplikasi tidak memerlukan pembuatan akun pengguna dan tidak berkomunikasi dengan server jarak jauh.

5. Privasi Anak-anak (Kepatuhan COPPA)

Aplikasi tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak di bawah usia 13 tahun. Sangat aman untuk semua kelompok usia.
