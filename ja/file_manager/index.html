ファイルマネージャー について

マルチタブのブラウジング、高速検索、アーカイブ圧縮/解凍 (ZIP、7z、RAR)、暗号化された金庫、および内蔵メディア プレーヤーを備えたフル機能のファイル マネージャーです。

主な機能と特徴

デュアルペインとタブナビゲーション

内部ストレージ、SD カード、USB ドライブにわたるファイルを簡単に管理します。

安全な保管庫

パスワードと生体認証で保護された、機密ファイルの暗号化ストレージ。

アーカイブサポート

パスワードをサポートし、ZIP、7Z、TAR、RAR ファイルを直接圧縮および抽出します。

内蔵メディアプレーヤー

サードパーティのアプリを使用せずに画像、ビデオ、オーディオ、ドキュメントをプレビューします。

ストレージアナライザー

大きなファイル、重複、冗長キャッシュを視覚的に分類します。
